## Friction, ranked (→ BACKLOG `[friction]`)
1. **`check` missing while the guide mandates it** — all 8 runs. Rule 1 vs workflow page contradicted each
   other. (Guide fixed this round; the command is the top backlog item.)
2. **Separate audio source silently misaligned** (correctness): `"audio": "mic"` in timeline.json rendered
   the recorder 1.7 s late with no warning. No `sync`, no command to choose the audio source.
3. **Nothing works on the render**: `look`, `listen`, `transcribe` only take sources (5/8 wanted them on
   `out/final.mp4`); agents fell back to ffmpeg/whisper-cli or scratch projects.
4. `transcript --words --from 38 --to 63` past the end printed only a header — say "no words in range (source is 30.3 s)".
5. `--dry-run` output "cut talk …" reads as done → "would cut …".
6. `transcript --suspects` keeps listing suspects already inside cut spans → mark them "(cut)" when a timeline exists.
7. `listen` printed `BLANK_AUDIO]` — whisper annotation tokens leak; strip `[…]` annotations.
8. `init` doesn't say what it wrote (`cutroom.json`); no command to remove a source.
9. `timeline` doesn't show which source supplies the audio.

## Observations
- Text-anchored cuts, the phrase view with `[repeat]`, `--dry-run` and `timeline --joins` were named "best part"
  by most agents. No agent mis-cut a word.
- Validator warnings steer agents: `retake-kept` led both phone-footage agents to remove a retake they weren't
  asked to. Probably right for real footage; worth phrasing as "if unintended" once `check` exists.
- Weaker model used ~40% more commands but reached the same result.
