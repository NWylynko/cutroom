   0.0". The offset is counted in decoded source frames; across a dropped-frame gap the renderer correctly
   holds a frame, so index ≠ time. Must measure in timestamps; identical frames are not a failure.
2. `transcript --file out/final.mp4` — read the render's own words (3 runs asked).
3. Bad-flag fix suggests `--o` for `-o`: map short flags to real long flags or to the positional arg.
4. Dry run of the first edit prints "created timeline" → "would create".
5. Validator: warn when a cut breaks a sentence (removes mid-sentence words that are not a retake/aside).
6. `transcript --suspects`: a repeat already resolved isn't marked "(already cut)" (sounds are).
7. `doctor`'s next: line uses a syntax that differs from the guide.
8. `sync` output: say plainly "the recorder is 1.700 s ahead"; `check` should name the audio reference.
9. `look` frame labels are nominal frame numbers on VFR sources — say so, or print the real pts.
